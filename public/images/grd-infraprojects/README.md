# GRD Infraprojects case study images

All 12 exports are 9:16 portrait (~460 x 818), laid out three to a row.
460 x 3 + 20px gaps = the 1420px content column, so they render at exactly
their design size.

No Figma spec was supplied for this page - the grouping below was read off the
artwork itself, and the section headings in `src/data/caseStudies.js` are
placeholders.
